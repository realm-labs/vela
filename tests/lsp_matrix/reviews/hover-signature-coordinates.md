# B07.1 hover and signature coordinate review

This child owns hover's UTF-16, CRLF, encoded-URI and repeated-request protocol
cells, plus signature-help's repeated-request cell. Syntax partitions, lifecycle,
schema replacement, provider smoke and UX10 retain their separate obligations.

The shared fixture authors 13 hover positions and 10 signature positions across
a caller and a defining helper. An unopened, unimported decoy declares the same
function with different parameter types and documentation. Complete expected
service metadata, local/source symbol ownership, protocol Markdown and signature
labels/parameters are committed explicitly. Expected classifications and content
never come from a provider result. Markers supply byte and UTF-16 coordinates
independently of production line indexing.

Hover checks the imported function, defining declaration, parameter/local
declaration and references, source field, imported constant and Any parameter.
Unresolved call/member and comment positions return none at service level and
explicit JSON null on the wire. Positive positions are queried at the token's
start and interior; both return the exact complete marked range. Local symbols
retain the independently marked declaration document and absolute byte range.
All results include exact label, kind, rendered type/signature and documentation;
protocol checks the complete Markdown object, including absent versus present
fields, rather than substring matches.

Signature checks both positional slots, reversed named labels, nested inner and
outer calls, default markers and unresolved/dynamic calls. Full signature lists,
active signature/parameter, parameter labels and service parameter names/types
are compared. Unchanged requests repeat identically before each source transition.

Both drivers run LF/CRLF, insert two preceding Unicode lines and restore the
original source. They compare every unchanged and repeated result against the
authored oracle; restoration matches the original complete result list. Protocol
uses real didOpen/didChange/didClose notifications, an encoded Chinese/space/percent
workspace path, and unopened defining/decoy files. Physical disk bytes stay fixed.
Surrogate-interior and beyond-line positions error for both requests, then every
valid query is rechecked. Closing restores exact disk-backed hover results.

The matrix exposed service byte columns leaking into hover responses after
Chinese/non-BMP text. Hover projection now converts both endpoints with the
same immutable snapshot text used for the query. Conversion failures use the
existing typed projection-error response path. The service remains byte-based;
signature content and runtime semantics do not change.

B00-B06 original acceptance snapshots stay fixed. Windows and macOS need fresh
independent evidence on their registered profiles; B16 stays deferred.
