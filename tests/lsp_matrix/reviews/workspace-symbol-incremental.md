# Workspace symbol incrementality and publication review

B10.13 closes the four positive/negative S11 service/protocol cells. S0 and
installed/native workspace picker remain open. No production or runtime change.

The source-only anonymous workspace has five files and nine literal phases:
initial, body receiver change/restoration, import owner switch, return declaration
change, missing import, import restoration, declaration rename and restoration.
The final return type remains Fourth. Removing `api::make` means renaming it to
`api::make_deleted`; substring queries still match that new row, while the whole
set and canonical identity forbid an old duplicate. Missing imports, local
receivers, fields and imported aliases add no global symbols. Real declarations
remain globally discoverable even when a caller is unresolved.

Each phase independently lists all nineteen ordered file/module/top-level rows
and seventeen complete query sets. Names, kinds, source identities, details,
containers and full marked declaration/file ranges are exact. `Fourth` matches
the struct only, even after a function's return detail becomes Fourth. Empty and
whitespace queries retain the full set; case/trim and qualified queries retain
their exact ordering. No provider output supplies expected values.

All phases run under LF/CRLF and two Unicode prefix lines. The main name starts
on line1/+2 at UTF16 columns15..19 but byte column19. Queries repeat three times
without changing generation or parse/project/HIR counters. Each change reparses
only its one document and rebuilds HIR once. Literal declaration/import
fingerprint flags control exactly one or zero project rebuilds. Literal reverse
dependency invalidation sets include the transitive relay when appropriate and
always exclude the unrelated module. Both service and actual typed open/change
dispatch compare the incremental state with independently initialized fresh
databases/coordinators and recheck every earlier immutable source/parse/symbol
snapshot after every later phase. Protocol uses private percent-encoded Chinese,
space and percent roots, exact UTF16 JSON-RPC envelopes and unchanged physical
source bytes beneath dirty overlays. Schema source locations stay absent.

Service publication checks use the existing generation/cancellation gates with
actual complete workspace-symbol values. Old generation results are rejected
by the current database but accepted by their owning old snapshot. For every
phase/query, cancellation before computation or after completed-result creation
prevents publication; a subsequent fresh request accepts the current authored
set without rebuilding. This checks publication rejection, not an unsupported
cancellable workspace-symbol computation API.

Protocol S11 also explicitly reuses the five accepted workspace-symbol worker
tests reviewed in [workspace-symbol-worker.md](workspace-symbol-worker.md).
They exercise real queue/completion/publication: ignored old document versions,
queued/completed cancellation, malformed and different typed IDs, cancellation
priority over stale work, exactly one current-generation retry across all source
and schema lifecycle phases, and ContentModified after retry exhaustion.
Their independently authored whole-set/error oracles and all original assertions
remain active. No extra retry policy or timing sleep is introduced.

Node checks the literal phase/fingerprint/invalidation inventory, complete ordered
memberships, return/rename transitions, negative probes and all transformed source
markers. Fresh platform acceptance is still required independently on each OS.
